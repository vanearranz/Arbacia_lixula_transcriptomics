## Analysis overview

Run the scripts in numerical order. They use paths relative to the repository
root through the R package `here`; no working directory needs to be set
manually.

### `01_deseq2_analysis.Rmd`

Performs the differential gene-expression analysis:

1. Imports `data/count_curated.csv` and `data/sample_metadata.csv`.
2. Validates sample identifiers, ordering, duplicated identifiers, missing
   values, and count-data integrity.
3. Retains genes with at least 10 counts in at least 4 samples(17,449 retained genes).
4. Fits a DESeq2 model with `design = ~ treatment`.
5. Calculates `CV vs CC`, `VV vs CC`, and `VV vs CV`.
6. Generates an exploratory PCA and sample-distance heatmap.
7. Saves complete DESeq2 tables, a DEG summary, the tested gene universe, and
   reusable DESeq2/VST objects under `results/`.

Positive log2 fold changes indicate higher expression in the first group named
in each contrast. Directional DEG summaries use `padj < 0.05` and
`abs(log2FoldChange) > 1`.

### `02_prepare_biomineralization_annotations.Rmd`

Reconstructs the biomineralization annotation workflow:

1. Imports the eggNOG-mapper annotation table.
2. Standardizes *Strongylocentrotus purpuratus* identifiers.
3. Joins eggNOG orthologues with the Dylus and Pespeni skeletogenic gene lists.
4. Retains one best eggNOG hit per *Arbacia lixula* gene using the lowest
   e-value and highest score.
5. Identifies biomineralization candidates and assigns broad functional
   classes.
6. Writes the processed annotations and candidate lists under
   `results/annotations/`.

The script preferentially uses `data/annotations/eggnog_annotations.csv`. It
can use the legacy pre-merged `eggnog_biomineralization.csv` if the original
eggNOG table is unavailable.

### `03_topgo_enrichment.Rmd`

Performs functional enrichment using `topGO`:

1. Imports the DESeq2 tables generated by script 01.
2. Imports `data/annotations/gene2go.tsv`.
3. Defines up- and down-regulated sets using `padj < 0.05` and an absolute
   log2-fold-change threshold greater than 1.
4. Uses tested genes with GO annotations as the enrichment universe.
5. Runs Fisher's exact test with the topGO `elim` algorithm for Biological
   Process, Molecular Function, and Cellular Component.
6. Saves complete and nominally significant (`P < 0.05`) enrichment tables
   under `results/topgo/`.

### `04_figures.Rmd`

Generates reproducible visualizations:

- DEG counts by contrast and direction;
- volcano plots for all three contrasts;
- VST heatmaps of significant genes;
- a mean-expression heatmap for biomineralization candidates.

Figures are written to `results/figures/`. Published figures and supplementary
results are available in the associated article.

## Required inputs

```text
data/
├── count_curated.csv
├── sample_metadata.csv
└── annotations/
    ├── eggnog_annotations.csv
    ├── gene2go.tsv
    ├── Skeletogenic_genes_dylus.tsv
    └── BiomineralizationGeneList_pespeni.xlsx
```

## Running the analyses

Clone the repository, open R in its root directory, and render the files in
order:

```r
rmarkdown::render("B.Analysis/01_deseq2_analysis.Rmd")
rmarkdown::render("B.Analysis/02_prepare_biomineralization_annotations.Rmd")
rmarkdown::render("B.Analysis/03_topgo_enrichment.Rmd")
rmarkdown::render("B.Analysis/04_figures.Rmd")
```

Generated outputs are written under `results/` and do not need to be tracked by
Git.

## R packages

Required packages:

- Bioconductor: `DESeq2`, `topGO`;
- CRAN: `dplyr`, `ggplot2`, `here`, `pheatmap`, `readr`, `readxl`,
  `RColorBrewer`, `rmarkdown`, `stringr`, `tibble`, and `tidyr`.

Each R Markdown file ends with `sessionInfo()` to record package versions.
