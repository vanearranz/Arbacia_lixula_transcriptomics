## Analysis overview

Run the scripts in numerical order. They use paths relative to the repository
root through the R package `here`; no working directory needs to be set
manually.

### `01_deseq2_analysis.Rmd`

Performs the differential gene-expression analysis:

1. Imports `data/count_curated.csv` and `data/sample_metadata.csv`.
2. Validates sample identifiers, ordering, duplicated identifiers, missing
   values, and count-data integrity.
3. Retains genes with at least 10 counts in at least 4 samples, matching the
   publication (17,449 retained genes).
4. Fits a DESeq2 model with `design = ~ treatment`.
5. Calculates the three contrasts:
   - `CV vs CC`: acute response to low-pH exposure;
   - `VV vs CC`: chronic response to low-pH exposure;
   - `VV vs CV`: genotype/origin effect under shared low-pH conditions.
6. Generates an exploratory PCA and sample-distance heatmap.
7. Saves DESeq2 tables, a DEG summary, the tested gene universe, and reusable
   DESeq2/VST objects under `results/deseq2/`.

Positive log2 fold changes indicate higher expression in the first group named
in each contrast. Directional DEG summaries use `padj < 0.05` and
`abs(log2FoldChange) > 1`.

### `02_go_enrichment_topgo.Rmd`

Performs functional annotation-based GO enrichment with topGO.

Functional annotation was obtained using
[eggNOG-mapper v2](https://doi.org/10.1093/molbev/msab293)
(Cantalapiedra et al., 2021). The longest transcript of each predicted
protein-coding gene in the *Arbacia lixula* reference genome was selected and
submitted to the eggNOG-mapper web server using the default settings.

The eggNOG-mapper output provided, for each *A. lixula* gene, its best seed
orthologue, eggNOG orthologous groups, functional descriptions, predicted gene
names, Gene Ontology terms, KEGG annotations, COG functional categories, and
PFAM protein domains. The processed annotation table is provided as:

```text
data/annotations/eggnog_annotations.csv
```

Gene-to-GO associations were extracted by retaining the query-gene identifier
and GO-term columns, removing comment lines, and converting comma-separated GO
terms to semicolon-separated terms:

```bash
grep -v '^#' MM__67_mntn.emapper.annotations.tsv |
  cut -f1,10 |
  sed 's/,/;/g' > gene2go.tsv
```

The resulting file is provided as:

```text
data/annotations/gene2go.tsv
```

The R Markdown script then:

1. Imports the DESeq2 tables generated by script 01.
2. Reads the eggNOG-derived gene-to-GO associations.
3. Defines up- and down-regulated sets using `padj < 0.05` and
   `abs(log2FoldChange) > 1`.
4. Uses the genes retained for DESeq2 that also have GO annotations as the
   enrichment universe.
5. Runs Fisher's exact test with the topGO `elim` algorithm for Biological
   Process, Molecular Function, and Cellular Component.
6. Saves complete and nominally significant (`P < 0.05`) enrichment tables
   under `results/topgo/`.

### `03_biomineralization_genes.Rmd`

Identifies and classifies candidate biomineralization-related genes.

The eggNOG-mapper seed orthologues assigned to *A. lixula* genes were matched
against two published echinoderm skeletogenic and biomineralization gene lists:

- `biomineralization_genes_pespeni.xlsx`: biomineralization-related genes
  compiled from the sea urchin study by
  [Pespeni et al. (2013)](https://doi.org/10.1073/pnas.1220673110),
  *Evolutionary change during experimental ocean acidification*.

- `skeletogenic_genes_dylus.tsv`: skeletogenic genes compiled from the
  developmental transcriptomic study of the brittle star *Amphiura filiformis*
  by [Dylus et al. (2018)](https://doi.org/10.1186/s13059-018-1402-8),
  *Developmental transcriptomics of the brittle star Amphiura filiformis
  reveals gene regulatory network rewiring in echinoderm larval skeleton
  evolution*.

The script:

1. Standardizes *Strongylocentrotus purpuratus* identifiers (`SPU` IDs).
2. Joins eggNOG orthologues with the Dylus and Pespeni gene lists.
3. Retains one best eggNOG hit per *A. lixula* gene using the lowest e-value
   and, in the case of ties, the highest score.
4. Assigns broad functional classes used for visualization:
   - extracellular-matrix structure;
   - extracellular-matrix remodeling and proteolysis;
   - extracellular-matrix-associated signaling and adhesion;
   - ion transport and calcium support;
   - other or unclassified functions.
5. Writes processed annotations and candidate lists under
   `results/annotations/`.

These lists identify candidate biomineralization-related genes and do not
represent direct functional validation in *A. lixula*.

### `04_figures.Rmd`

Generates reproducible visualizations:

- DEG counts by contrast and direction;
- volcano plots for all three contrasts;
- VST heatmaps of significant genes;
- a mean-expression heatmap for biomineralization candidates.

Figures are written to `results/figures/`. Published figures and supplementary
results are available in the associated article.

## Required inputs

```text
data/
├── count_curated.csv
├── sample_metadata.csv
└── annotations/
    ├── eggnog_annotations.csv
    ├── gene2go.tsv
    ├── skeletogenic_genes_dylus.tsv
    └── biomineralization_genes_pespeni.xlsx
```

## Running the analyses

Clone the repository, open R in its root directory, and render the files in
order:

```r
rmarkdown::render("analysis/01_deseq2_analysis.Rmd")
rmarkdown::render("analysis/02_go_enrichment_topgo.Rmd")
rmarkdown::render("analysis/03_biomineralization_genes.Rmd")
rmarkdown::render("analysis/04_figures.Rmd")
```
